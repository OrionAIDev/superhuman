# hello-cli

A tiny Python command-line tool that prints a greeting. It exists as a canonical
fixture for smoke-testing the superhuman skill: small enough to read at a glance,
real enough to drive the full gate sequence.

## Usage

```bash
python hello_cli.py greet --name World
# -> Hello, World!

python hello_cli.py --version
# -> hello-cli 0.1.0
```
